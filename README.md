# Стайка

Приложение для компаний друзей и коллег: общий обед, голосование «куда пойдём» с колесом, события и игры для вечеринок.

- Русский, английский и греческий.
- Аватарка (фото по желанию), согласие и права по GDPR, удаление всех данных в два нажатия.
- 11 игр по 150 карточек в каждой, на трёх языках: с алкоголем (18+), для ума, микс и «18+ Разговоры» (личные и провокационные вопросы без сексуального содержания).
- Режим «Без алкоголя» включён по умолчанию.
- Пока это Android-приложение с данными только на телефоне. Синхронизации между друзьями ещё нет (см. «Что дальше»). iPhone позже.

## Как это устроено

Так же, как Нора и Talent Foxes: веб-приложение на Vite и обычном JavaScript, упаковано в Android через Capacitor.
APK собирает GitHub Actions (`.github/workflows/android.yml`) после каждого изменения в `main`. Готовый APK
публикуется на странице Releases / latest репозитория: откройте её на телефоне и скачайте `stayka.apk`.

```
index.html        вход
src/main.js       экраны и логика
src/games.js      каталог игр, правила, категории
src/games/*.js    карточки, по одному файлу на игру: массив [ru, en, el], в формате JSON
src/native.js     кнопка «Назад» на Android
src/styles.css    оформление
android/          проект Android (Capacitor), шаблон из Норы
test/             проверка карточек: по 150 штук, три языка, без повторов
tools/            check_cards.py и check_alphabets.py: то же самое без Node
```

## Первый запуск

1. Создайте пустой **приватный** репозиторий `stayka` на GitHub и отправьте в него этот проект (ветка `main`).
2. **Actions** → «Android APK» → Run workflow. Дальше сборка идёт сама при каждом push.
3. Откройте на телефоне Releases / latest и скачайте `stayka.apk`.

Ключ подписи `android/app/stayka.jks` лежит в репозитории по той же схеме, что в Норе и Talent Foxes (репозиторий приватный):
им подписаны все сборки, поэтому APK обновляется поверх прежнего. Пароль и алиас записаны в `android/app/build.gradle`.
Если репозиторий станет публичным или приложение пойдёт в Google Play, ключ нужно заменить: для Play добавьте секрет
`UPLOAD_KEYSTORE_PASSWORD` и файл `android/app/upload.jks` (CI восстанавливает его из секрета). SHA-1 тестового ключа:

```
F0:25:84:FF:A2:CE:E9:BF:E1:96:1E:A2:07:CC:38:1C:C7:4E:FF:76
```

`package-lock.json` пока нет (проект создан на машине без Node), поэтому CI вызывает `npm install`, а не `npm ci`.
После первой успешной сборки закоммитьте появившийся `package-lock.json` и верните `npm ci` в workflow.

## Шрифты и GDPR

Шрифты Onest и Unbounded идут из npm (`@fontsource`) и вшиваются в приложение. Запросов к Google Fonts нет: иначе
IP-адрес пользователя уходит в Google, а это нарушение GDPR. У шрифтов нет греческих букв, греческий текст рисуется
системным шрифтом.

Тексты политики в `src/main.js` (функция `policy`) описывают текущее состояние: данные только на телефоне, никуда не
отправляются. Это черновик: перед публикацией заполните оператора и контакты и покажите текст юристу, греческую версию
должен прочитать носитель языка. Когда появится Firebase, политику и согласие нужно обновить и спросить заново.

## Google Play

- Тут две зоны риска: игры с алкоголем и раздел 18+. Анкета возрастного рейтинга должна честно отражать оба. Разделы
  закрыты подтверждением возраста, алкогольные игры не призывают пить (есть «Без алкоголя», вода и штрафные задания).
- Карточки «18+ Разговоры» остаются на уровне личных и провокационных вопросов без сексуального содержания. Так же сделана
  Нора, поэтому правило сохраняется для всех новых карточек.
- В манифесте только `INTERNET`, без push, геолокации и контактов.

## Данные

Всё хранится в `localStorage` приложения. Профиль, согласие, ответы на обед, голосования и события лежат одним
документом под ключом `stayka-v2`.

## Разработка

```
npm install
npm run dev              # веб-версия в браузере
npm test                 # проверка карточек
npm run sync             # собрать веб и обновить android/
python tools/check_cards.py
```

Без Node можно открыть `index.html` через любой статический сервер (`python -m http.server`): приложение работает, только
шрифты не подтянутся. Сборка APK локально требует Android SDK и JDK 21: `cd android && ./gradlew assembleRelease`.

## Что дальше

4. **Свои игры**: добавить карточки группы и общий рейтинг мест.

## Что нового

- Название приложения: **Стайка**.
- Создание компании (кнопка «＋» в шапке), приглашение по коду и ссылке на приложение, вступление по коду. Общие данные между телефонами заработают вместе с синхронизацией.
- Профиль и другие окна закрываются свайпом вниз (или нажатием на «ручку» сверху, или на затемнённый фон).
- Семь цветовых схем и выбор «светлая / тёмная / как в системе» в профиле.
- Google Карты без ключа API и без запросов из приложения: кнопки «На карте», «Маршрут», «Поделиться»; место можно выбрать в Картах и отправить в Стайку через меню «Поделиться» (приложение принимает текст), чтобы сразу позвать на обед, создать событие или добавить вариант в голосование.
- Синхронизация через Firebase (анонимный вход + Cloud Firestore): общие обеды, голосования, события, профили участников, вступление по коду. Включается заполнением `src/firebase-config.js`, шаги в [docs/FIREBASE.md](docs/FIREBASE.md). Пока конфиг пуст, приложение работает как раньше, на одном телефоне.
- iPhone: веб-версия через GitHub Pages и неподписанный .ipa (workflow «iOS app»), инструкция в [docs/IOS.md](docs/IOS.md).
- Google Play: подготовка и чек-лист в [docs/PLAY_STORE.md](docs/PLAY_STORE.md), графика в `store/`, политика в `public/privacy.html`.
